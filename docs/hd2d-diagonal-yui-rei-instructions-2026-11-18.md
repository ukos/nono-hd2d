# ユイ＆レイ 斜め方向 生成指示文（2026-11-18）

nono で効いた v3 の型（「3コマとも完全に同じ向き、違いは足だけ」＋各コマの足指定）で書いた。
必要な生成は1人あたり斜め3帯（南東・南西・北東）だけ。北西は北東の反転、西は既存の横行の反転で作るので生成不要。

添付の使い分け：
- 南東・南西：正面イラスト1枚だけ（歩行シートを渡すと定番3方向に引っ張られるため）
- 北東：正面イラスト＋背面見本（yui_back_sample.png / rei_back_sample.png）。背面の装備配置は正面から読み取れないため

# ユイ

## ユイ・南東（右下）

添付のキャラクター（正面イラスト）と完全に同一のデザイン・配色・頭身のドット絵で、歩行アニメーション3コマを横に並べた帯状の画像を描いてください。背景は鮮やかなマゼンタ（#FF00FF）一色。枠線・文字・地面の影は入れない。

3コマとも完全に同じ「右下を向いた斜め前（45度）」の向きです。方向の見本並べではありません。3コマの違いは足の位置だけです。
- 1コマ目：左足が前、右足が後ろに開いた歩行ポーズ
- 2コマ目：両足が揃って着地した中間ポーズ（体の向きは1コマ目と全く同じ）
- 3コマ目：右足が前、左足が後ろに開いた歩行ポーズ

顔は3/4向きで両目が見える。体の左側が見える側で、左腰に吊るした細剣の金の柄が手前に見える。背中の弓は右肩の後ろに先端が覗く程度。足元まで届く長い髪は体の両側に流れ、歩行に合わせてわずかに揺れる。

足元まで届く長い金髪（ストレート、前髪あり）、青い目。白の軍服風ジャケット（金のボタン2列、金の肩章、立ち襟）。金色の幅広い腰帯。左腰に金の籠手つきの柄の細剣。背中に弓を斜めに背負う。白のズボン、グレーのロングブーツ。

全コマで大きさと足元の位置を統一し、コマごとに拡大・縮小しない。正面・真横・真後ろを描かない。写実化・水彩化をしない。背景はマゼンタ一色。

## 生成後の扱い

- 6帯そろったら送ってもらう。nono が検品（顔の向きと装備の見え方で方向を判定。nono のとき盾の大きさで判定して取り違えたので、今回は顔の向きを主基準にする）→ 透過化 → 既存の3方向と合成して8方向アトラス化。
