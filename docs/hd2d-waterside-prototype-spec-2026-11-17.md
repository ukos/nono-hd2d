# NONO: Blade of the Dawn ― HD-2D試作「水辺」シーン仕様書

検証リスト（hd2d-prototype-checklist-2026-11-17.md）の実施用仕様。
目的は見た目と成立性の判定だけ。ゲームロジックは作らない（歩行とカメラ追従のみ）。

## 1. シーン構成（1画面＋少し歩ける範囲）

- 舞台：夕景の湖畔（または川辺）。画面の手前〜中央に水面、奥に岸と地形
- レイヤー構成（奥から）：
  1. 遠景：山並み・空（既存背景の流用または単色グラデーション＋シルエット）
  2. 中景：対岸の地形、木々（3Dのローポリ、または板ポリにドット絵テクスチャ）
  3. 地面：歩行エリアの岸（3Dジオラマ。水際で段差を作る）
  4. 水面：反射とゆらぎのある平面（§3）
  5. 手前：水際の草・小石・流木（カメラに近い層。被写界深度でぼける側）
- 配置物：nono（歩行アニメのみ）、ライバル1体（静止でよい。影の出方と並んだ時の画を見るため）
- 時間帯：夕方固定（斜め光・長い影・水面の照り返しが一番出るため）

## 2. カメラ

- Perspective カメラ。画角は 30〜40 度、斜め見下ろし（HD-2D の標準的な角度）
- キャラクター追従は緩やかに（即時追従にしない）
- スプライトはビルボードにせず、地面に垂直に立てる（HD-2D の作法）。影はスプライトの形で落ちる設定にする

## 3. 水面

- 方式は軽い順に検討し、見た目が足りなければ一段上げる：
  1. 半透明＋スクロールするノーマル風テクスチャでゆらぎ表現（最軽量）
  2. URP 向けの簡易ウォーターシェーダー（反射は環境色＋光のグリントのみ）
  3. リアルタイム反射（Reflection Probe / Planar Reflection）は WebGL で重いので試作では使わない
- 波紋：nono が水際を歩いたとき足元に小さな波紋リングが出る（1つだけの演出として入れる）

## 4. ライティングとポストプロセス（URP）

初期値（ここから調整する出発点）：

- Directional Light：夕日の色（暖色寄り）、角度は低め（長い影）。シャドウ有効
- Ambient：空の色を拾う程度に弱く
- Volume（Post-processing）：
  - Bloom：弱め（水面の照り返しと光源だけがにじむ程度）
  - Depth of Field：Bokeh または Gaussian。焦点はキャラクターの列、手前と奥をぼかす
  - Color Adjustments / Tonemapping：ACES、彩度は元絵を壊さない範囲
  - Vignette：ごく弱く（任意）

## 5. スプライト取り込み

- 既存スプライトシートをそのまま使う
- Import 設定：Texture Type = Sprite (2D and UI)、Filter Mode = Point (no filter)、Compression = None、Pixels Per Unit はシートの規格に合わせる
- 歩行アニメは既存の歩行シートから Animation Clip を作る（工数を実測してチェックリスト §5 に記録）

## 6. 操作（最小）

- キーボード：矢印/WASD で8方向歩行
- タッチ：画面左半分の仮想スティック（仮でよい）
- それ以外のアクション（攻撃・ジャンプ等）は試作に入れない

## 7. WebGL ビルド設定

- Player Settings：
  - Compression Format：Decompression Fallback を有効化（GitHub Pages 対策）
  - WebGL2 前提（iPhone Safari の現行対応範囲）
  - 初期表示はタイトル画像を先に出し、ロード完了でシーンへ（ロード待ちの体感対策）
- 公開先：`nono-playground/hd2d-test/`（本編と隔離）
- ビルド後に実測してチェックリストへ記録：総MB、最大ファイルMB、初回ロード秒数（Wi-Fi／4G）、fps

## 8. 完成の定義（試作として）

- [ ] スクリーンショット3枚（全景／水際アップ／手前の草越し）を撮って見た目判定に使う
