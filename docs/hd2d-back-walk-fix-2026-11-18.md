# HD-2D lite：後ろ向き歩行が滑って見える件 — 原因と直し方（2026-11-18）

## ユーザー報告
2026-11-18 14:32 JST、実機チェックの結果：「後ろ向きにあるく 滑っているように見える」
（直前に公開した8方向アトラス版へのフィードバック）

## 原因（検証済み）
真後ろ（北・N行）の歩行コマ自体に、歩いていると読める足の動きがほぼ無い。

- 検証：`~/workspace/hd2d-lite/assets/nono_sheet8b.png`（8行×3列、528×1792、各コマ176×224）を全行測定。
  - 足元ゾーン（各コマ下部50px）のバウンディングボックス：
    - 南（正面）行：フレーム間で x 20〜155 ⇄ 31〜144 と大きく振れる（歩幅あり）
    - 北（背面）行：x 32〜149 / 30〜147 / 32〜149 とほぼ不変。しかも外側の2コマ（1コマ目と3コマ目）がほぼ同一ポーズ（ピクセル数 2875 vs 2840）で、左右の振り分けになっていない
    - 北東・北西（斜め後ろ）行：足はちゃんと振れている（x 44→48→41 など）ので、問題は真後ろ行だけ
- 出どころ：これは生成ミスではなく公式シート由来。`~/workspace/hd2d-lite/assets/nono_sheet.png`（公式3行シート）の背面行そのものが同じ構図で、マントが脚を隠しブーツが数pxしか動かない。正面・横行は交互にはっきり振れている。
- コード側の悪化要因：`index.html` 513行目 `STEP_LENS` の北行だけ 0.29m（他は 0.38〜0.42m）。
  歩行位相は `walkPhase += moved / STEP_LENS[dirRow]`（537行目）で進むため、北行は正面より約45%速くコマが切り替わる。
  ほぼ同じ絵の高速シャッフル＝「滑り」に見える、という構図。

## 直し方（2段構え）
### (a) コードだけの緩和策（すぐできる・可逆・公開にはユーザーのpush承認が必要）
`~/workspace/hd2d-lite/index.html`（公開コピー `~/workspace/hd2d-deploy/hd2d-test/index.html` と同一内容を確認済み）：

```diff
 // 方向ごとの歩幅（描画の足の開きに合わせる。背面は歩幅が小さい絵なので短く）
-const STEP_LENS = [0.42, 0.40, 0.42, 0.38, 0.29, 0.38, 0.42, 0.40];
+const STEP_LENS = [0.42, 0.40, 0.42, 0.38, 0.42, 0.38, 0.42, 0.40];
+// 方向ごとの上下動[m]。背面は足が見えにくいので体の上下動を大きくして歩行感を出す
+const BOB_AMPS = [0.035, 0.035, 0.035, 0.04, 0.06, 0.04, 0.035, 0.035];
```

```diff
-      player.position.y = Math.abs(Math.sin(walkPhase * Math.PI)) * 0.035; // 歩行の上下動
+      player.position.y = Math.abs(Math.sin(walkPhase * Math.PI)) * BOB_AMPS[dirRow]; // 歩行の上下動
```

- 効果：北行のコマ送りが正面と同じテンポに戻り、体の上下動が 3.5cm → 6cm になって「歩いている」手がかりが増える。
- 限界：絵に無い足の振りをコードで生み出すことはできない。緩和策どまり。

### (b) 根本の直し：背面行の描き直し（外部AIへの指示文・v3流）
北行だけ、斜め生成で効いた v3 の型（「3コマとも完全に同じ向き、違いは足だけ」＋足の位置まで指定）で再生成する。
添付：正面イラスト（デザイン見本）＋現行の背面行（向きの見本）。

> 添付のキャラクター（正面イラスト）と完全に同一のデザイン・配色・頭身（約2.5頭身）のドット絵で、歩行アニメーション3コマを横に並べた帯状の画像を描いてください。背景は鮮やかなマゼンタ（#FF00FF）一色。枠線・文字・地面の影は入れない。
>
> 3コマとも完全に同じ「真後ろ」の向きです。方向の見本並べではありません。3コマの違いは足の位置だけです。
> - 1コマ目：左足のブーツが後ろに大きく振り出され、右足が前にある歩行ポーズ。マントの裾が左側に持ち上がる
> - 2コマ目：両足が揃って着地した中間ポーズ（体の向きは1コマ目と全く同じ）
> - 3コマ目：右足のブーツが後ろに大きく振り出され、左足が前にある歩行ポーズ。マントの裾が右側に持ち上がる
>
> 顔は見えず、後頭部と濃い赤のマントが主体。ブーツはマントの裾の下から、左右どちらのコマでもはっきり見える大きさで描く（裾に隠して小さくしない）。体の左側が見える側で、左腕の盾は裏側（内側）が見える角度にし、盾の表面（木目と中央のボス）をこちらに向けない。背中の剣は斜め掛けに見え、柄は右肩の上、つまり画面では頭の右側に出る。
>
> 明るい茶色のロングヘア。金の縁取りのある青いロングチュニック、首元で結んだ濃い赤のマント。茶色のベルト。クリーム色のズボン、茶色のブーツ。左腕に丸い木の盾。背中に剣を背負う。
>
> 全コマで大きさと足元の位置を統一し、コマごとに拡大・縮小しない。真横・斜め後ろを描かない。写実化・水彩化をしない。背景はマゼンタ一色。

- 受け取ったら nono が検品（1・3コマ目の足が左右対称に振れていること）→ 北行だけ差し替えてアトラス再合成 → 公開、の流れ。剣の柄の肩は、現行の生成3帯と同じく公式と逆に出る可能性がある（試作では許容済み・2026-11-18確認）。
